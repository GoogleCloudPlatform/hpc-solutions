REST API Documentation

  • GET /health - Returns service operational status
  • GET /api/experiments - Lists AlphaEvolve experiments in GCP project across all sessions
  • GET /api/status?exp=<EXPERIMENT_ID> - Returns live progression statistics & candidate evaluation counts
  • GET /lineage?exp=<EXPERIMENT_ID> - Interactive Evolutionary Forest Graph Visualizer (Child/Parent/Sibling relationships & Code Inspector)
  • GET /api/lineage?exp=<EXPERIMENT_ID> - JSON ancestry tree & per-node metadata
  • GET /api/program_code?exp=<EXPERIMENT_ID>&prog=<PROGRAM_ID> - Returns program details and source code files
