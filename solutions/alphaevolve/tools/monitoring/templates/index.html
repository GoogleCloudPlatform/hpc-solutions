Programmatic REST API Endpoints

Method Endpoint Description
GET /health Returns Cloud Run service operational health status.
GET /api/experiments Lists all AlphaEvolve experiments discovered in the configured GCP project across sessions.
GET /api/status?exp=<EXPERIMENT_ID> Returns live generation progress, token consumption, and candidate evaluation trajectory.
GET /api/lineage?exp=<EXPERIMENT_ID> Returns the full evolutionary ancestry forest graph and per-candidate score metadata.
GET /api/program_code?exp=<EXPERIMENT_ID>&prog=<PROGRAM_ID> Retrieves unflattened candidate program source files and evaluation insights.
GET /api/program_diff?exp=<EXPERIMENT_ID>&prog=<ID>&base=<BASE_ID> Computes side-by-side and unified line diffs between two candidate programs.
GET /api/explain_evolution?exp=<EXPERIMENT_ID>&prog=<ID>&base=<BASE_ID> Generates and caches a Vertex AI Gemini explanation of code mutations and score deltas.
